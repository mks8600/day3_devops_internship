## 📝 Interview Questions Answered
1. **What is Git?**  
   Distributed version control system for tracking code changes.

2. **Merge vs Rebase**  
   Merge preserves history; rebase creates linear timeline.

3. **Pull Request**  
   Request to merge changes after team review.
